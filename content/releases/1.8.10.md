## AS-IS

Everything from v1.0.0 to v1.8.9 is unchanged. No screen, field or behaviour was removed.

## Fixes

- **`can't open file '…/mobile/.github/scripts/android-signing-config.py'`.** The build job sets `working-directory: mobile`, so every step runs from the app's own folder. Two steps called scripts as `.github/scripts/…`, which from there means `mobile/.github/scripts/…` — a folder that does not exist. The three `report.mjs` steps had `working-directory: .` and were right; these two never did.

  Both now call `../.github/scripts/…`, reaching the repository root from the job's own directory.

  This failed **after** signing succeeded, which is worth noting: the keystore work from v1.8.9 did run, and ran correctly.

## Updates / Modifications

- **The two Python scripts are now Node**, to match the stack: Next.js and Node on the platform, React Native on the phone, nothing else.

  - `android-signing-config.py` → **`android-signing-config.mjs`**. Same job, same output.
  - `play-upload.py` → **`play-upload.mjs`**, and it no longer installs anything. It talks to Google's Publishing API over plain HTTPS: a service-account JWT signed with Node's own crypto, exchanged for an access token, then four REST calls. No SDK, no `pip install`, nothing between the key and Google.

  The `python3 -m pip install` line is gone with them, which also takes a slow step out of every store build.

## Verified

`npm test` — seventeen new checks beside the existing ones, none needing a runner:

- the workflow runs **no Python at all**, and every script it names is Node;
- **every script path resolves to a file that exists**, from the directory that step actually runs in — the exact bug above;
- the signing-config rewrite adds the release config, points the release build at it, leaves the debug build and the existing debug keystore alone, and changes nothing when run twice (prebuild can run more than once, and so can it).

## What to do

Push `.github/` and build again. The two `.py` files are deleted — remove them from your repository too, or they will sit there doing nothing.
