## AS-IS

Everything from v1.0.0 to v1.8.1 is unchanged. No screen, field or behaviour was removed. Two bugs are fixed, both of which stopped a build starting.

## Fixes

- **A build was refused for `MOBILE_BUILD_SECRET` even though the platform keeps one.** This is a regression from v1.8.1. That release taught the set-up panel that a secret kept by the platform is not a missing one, by giving `readyToBuild()` a map of what the platform holds — but `startBuild()` still called `readyToBuild()` with nothing. So the panel showed a green tick and an enabled button, and the build itself answered *"Not set up yet — missing MOBILE_BUILD_SECRET"*. The gate is now given the same knowledge the panel has, and the secret is made **before** the gate is checked rather than after, since it is one of the things the gate looks for.

  The general lesson is in the code as a comment: when the thing that decides and the thing that displays are told different stories, only one of them is on screen.

- **"Every company that already has an app (0)" could be ticked, and did nothing.** Nobody can have an app before the first one is built, so with a count of zero that option is a guaranteed no-op — and it answered *"0 builds started"*, which says what happened and not one word about why. Now:
  - it cannot be ticked while the count is zero, and unticks itself if the count falls to zero;
  - the reason sits under it: *"No company has an app yet, so there is nothing to rebuild. Pick a company above and build its first one."*;
  - **Start build** is disabled rather than pressable-but-pointless;
  - if the request is made anyway, the platform refuses it with that reason instead of a silent zero;
  - a bulk build that starts nothing for some other reason now reports the first actual problem rather than a bare count.

- **A first build says so.** Building a company that has no app reports *"First build started — it takes 10–20 minutes and fixes this company's application id."*, because that build decides something permanent.

## Verified

The gate logic is covered by a test of all eight cases — with and without the platform-held secret, an environment-set secret, a too-short one, a `https://…​.git` repository and a workflow without `.yml`. All pass. It needs no database, so it runs anywhere.
